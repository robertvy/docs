Use this guide if your existing number setup already runs in Placetel.

<Steps>
  <Step title="Get Placetel SIP credentials">
    1. Log in to your [Placetel](https://web.placetel.de) account
    2. Go to **Einstellungen → SIP-Konten** (Settings → SIP Accounts)
    3. Create a new SIP account or use an existing one
    4. Note the SIP server, username, and password
  </Step>
  <Step title="Create SIP Trunk in itellicoAI">
    Go to **Telephony → SIP Trunks → Create SIP Trunk**:
    - **Name:** Placetel
    - **Termination URI:** Placetel's SIP server address
    - **SIP Auth Username/Password:** Your Placetel SIP credentials
  </Step>
  <Step title="Set up routing">
    In Placetel, configure call forwarding or routing rules to direct calls to the itellicoAI SIP endpoint.
  </Step>
</Steps>
