## Anbieter-Kataloge sind dynamisch

Die Verfügbarkeit von Anbietern, Modellen und Stimmen wird aus den Plattform-Katalogen generiert und kann sich im Laufe der Zeit ändern.

Nutze diese Seite als Funktionsreferenz und verwende die Providers API, um die genauen Optionen abzurufen, die zur Laufzeit für dein Account verfügbar sind.

---

## Aktuelle Anbieter-Familien

### LLM-Anbieter

- OpenAI
- Azure OpenAI
- Anthropic
- Groq
- Benutzerdefiniert (OpenAI-kompatibel)

### STT-Anbieter (Transkription)

- Deepgram
- Azure Speech

### TTS-Anbieter (Stimme)

- Azure Speech
- Cartesia
- ElevenLabs

<Note>
Genaue Modelle und Stimmen sind account- und laufzeitabhängig und können ohne ein Docs-Release hinzugefügt, entfernt oder neu priorisiert werden.
</Note>

## Providers API (Quelle der Wahrheit)

Verwende deinen API-Schlüssel und deine Account-ID, um aktuell verfügbare Optionen abzurufen.

### LLM-Modell-Katalog auflisten

```bash
curl -H "X-API-Key: <your-api-key>" \
  "https://api.itellico.ai/v1/accounts/<account_id>/providers/models"
```

### Transkriptions-Katalog auflisten

```bash
curl -H "X-API-Key: <your-api-key>" \
  "https://api.itellico.ai/v1/accounts/<account_id>/providers/transcribers"
```

### Stimmen auflisten (Live-Anbieterdaten)

```bash
curl -H "X-API-Key: <your-api-key>" \
  "https://api.itellico.ai/v1/accounts/<account_id>/providers/voices?provider=elevenlabs"
```

- `provider` unterstützt aktuell: `azure`, `cartesia`, `elevenlabs`
- optionale Filter: `language`, `gender`, `search`, `limit`, `refresh`
