## Überblick

API-Schlüssel geben deinem System Zugriff auf den jeweiligen Account-Kontext. Erstelle pro Account getrennte Schlüssel und behandle sie wie Secrets.

## Best Practices

- nutze getrennte Schlüssel pro Umgebung
- rotiere Schlüssel regelmäßig
- widerrufe kompromittierte Schlüssel sofort
- gib Schlüssel nie im Klartext weiter
