**Beta-Funktion** - Der Model Context Protocol (MCP)-Server befindet sich derzeit in der Beta. Verbinde KI-Anwendungen direkt mit der itellicoAI-Dokumentation.
</Note>

## Gehosteter MCP-Server

Nutze unseren gehosteten MCP-Server, um verfügbare Tools zu erkunden.

### MCP-Server-URL

Nutze die folgende URL, um KI-Anwendungen mit deiner Dokumentation zu verbinden:

```
https://docs.itellico.ai/mcp
```

---

## Verfügbare Tools

### SearchItellicoAi

Durchsuche die Wissensdatenbank von itellicoAI, um relevante Informationen, Codebeispiele, API-Referenzen und Anleitungen zu finden.

**Nutze dieses Tool, wenn du:**
- Fragen zu itellicoAI beantworten willst
- Bestimmte Dokumentation finden willst
- Verstehen willst, wie Funktionen arbeiten
- Implementierungsdetails finden willst

**Gibt zurück:**
- Kontextbezogene Inhalte mit Titeln
- Direkte Links zu Dokumentationsseiten

---

## Deine KI-Anwendung verbinden

<Steps>
  <Step title="MCP-URL kopieren">
    Kopiere die MCP-Server-URL: `https://docs.itellico.ai/mcp`
  </Step>

  <Step title="KI-Client konfigurieren">
    Füge den MCP-Server der Konfiguration deiner KI-Anwendung hinzu
  </Step>

  <Step title="Loslegen">
    Deine KI kann die itellicoAI-Dokumentation jetzt direkt durchsuchen und referenzieren
  </Step>
</Steps>

---

## Beispielnutzung

Wenn die Verbindung steht, kann dein KI-Assistent die Dokumentation durchsuchen:

```
User: "How do I create an agent with Python SDK?"
AI: [Uses SearchItellicoAi tool]
AI: "Here's how to create an agent with the Python SDK..."
```

Das Tool bietet direkten Zugriff auf:
- API-Referenzen
- SDK-Dokumentation
- Einrichtungsanleitungen
- Codebeispiele
- Best Practices
