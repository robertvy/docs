## Text Items

### Was sind Text Items?

Text Items sind manuell geschriebene Wissenseinträge. Nutze sie für kurze, strukturierte oder häufig aktualisierte Inhalte.

### Wie du ein Text Item hinzufügst

<Steps>
  <Step title="Knowledge Base öffnen">
    Öffne deine Knowledge Base und klicke auf **Add Item**.
  </Step>
  <Step title="Text Content wählen">
    Wähle **Text Content**.
  </Step>
  <Step title="Titel und Inhalt eingeben">
    Gib einen klaren Titel und den eigentlichen Inhalt ein.
  </Step>
  <Step title="Create klicken">
    Speichere das Item.
  </Step>
</Steps>

### Best Practices

<CardGroup cols={2}>
  <Card title="Ein Thema pro Item" icon="bullseye">
    Halte Items fokussiert.
  </Card>
  <Card title="Klar und konkret" icon="comment">
    Schreib so, dass der Agent die Antwort leicht extrahieren kann.
  </Card>
</CardGroup>

### Wann du Text Items nutzen solltest

<AccordionGroup>
  <Accordion title="FAQs" icon="circle-question">
    Kurze, wiederholte Fragen und Antworten.
  </Accordion>
  <Accordion title="Policies" icon="shield">
    Kompakte Richtlinien und Regeln.
  </Accordion>
  <Accordion title="How-Tos" icon="list-check">
    Kurze Schrittfolgen oder Referenzinfos.
  </Accordion>
</AccordionGroup>

### Einschränkungen

<Tip>
Halte Text Items knapp. Wenn ein Thema sehr groß wird, splitte es in mehrere Items oder verwende eine Datei.
</Tip>

## File Upload Items

### Was sind File Upload Items?

Datei-Items sind hochgeladene Dokumente, die dein Agent später abrufen kann.

### Wie du ein File Item hinzufügst

<Steps>
  <Step title="Add Item">
    Klicke auf **Add Item**.
  </Step>
  <Step title="Upload File wählen">
    Wähle **Upload File**.
  </Step>
  <Step title="Datei auswählen">
    Lade die Datei hoch und vergebe einen Titel.
  </Step>
</Steps>

### Verarbeitungsdetails

Dateien werden verarbeitet und indexiert, damit der Agent relevante Abschnitte abrufen kann.

### Best Practices

<CardGroup cols={2}>
  <Card title="Saubere, klare Dateien" icon="file">
    Vermeide überflüssige Inhalte.
  </Card>
  <Card title="Relevante Ausschnitte" icon="scissors">
    Extrahiere nur den Teil, den der Agent braucht.
  </Card>
</CardGroup>

### Einschränkungen

Größe und Format müssen unterstützt sein.

### Troubleshooting

<AccordionGroup>
  <Accordion title="Datei verarbeitet nicht" icon="xmark">
    Datei ist möglicherweise beschädigt, zu groß oder passwortgeschützt.
  </Accordion>
  <Accordion title="Antworten sind ungenau" icon="magnifying-glass">
    Datei möglicherweise zu groß oder zu unscharf strukturiert. Splitte Inhalte besser auf.
  </Accordion>
</AccordionGroup>

## URL Items

### Was sind URL Items?

URL Items ziehen Inhalte von einer einzelnen öffentlichen Web-Seite.

### Wie du ein URL Item hinzufügst

<Steps>
  <Step title="Add Item">
    Klicke auf **Add Item**.
  </Step>
  <Step title="Web Page wählen">
    Wähle **Web Page**.
  </Step>
  <Step title="URL eingeben">
    Füge die Ziel-URL ein.
  </Step>
</Steps>

### Verarbeitungsdetails

Der Inhalt der Seite wird abgerufen und in die Knowledge Base aufgenommen.

### Best Practices

<CardGroup cols={2}>
  <Card title="Einfache Seiten" icon="globe">
    Nutze Seiten mit sauberem Text.
  </Card>
  <Card title="Stabile Inhalte" icon="clock">
    Gute Wahl für Inhalte, die sich selten ändern.
  </Card>
</CardGroup>

### Einschränkungen

<Note>
Seiten mit Authentifizierung oder starkem JavaScript sind möglicherweise ungeeignet.
</Note>

### Troubleshooting

<AccordionGroup>
  <Accordion title="Scrape fehlschlägt" icon="xmark">
    Prüfe URL, Zugriff und Seitenstruktur.
  </Accordion>
</AccordionGroup>

## Website Crawl Items

### Was sind Website Crawl Items?

Website Crawl Items entdecken und importieren mehrere Seiten von derselben Website.

### Wie du einen Website Crawl hinzufügst

<Steps>
  <Step title="Add Item">
    Klicke auf **Add Item**.
  </Step>
  <Step title="Website Crawl wählen">
    Wähle **Website Crawl**.
  </Step>
  <Step title="URL eingeben und entdecken">
    Füge die Website ein und nutze **Discover URLs**.
  </Step>
</Steps>

### Crawl-Einstellungen

Lege fest, wie viele Seiten entdeckt und aktualisiert werden sollen.

### Einschränkungen

Crawler sollten für öffentliche, gut strukturierte Websites genutzt werden.

## Die richtige Content-Art wählen

Nutze Text für kurze Inhalte, Dateien für Dokumente, URL für einzelne Seiten und Website Crawl für mehrseitige Websites.
