Agenten-Demo-Links lassen dich eine browserbasierte Version deines Agenten an andere Personen senden, ohne ihnen Zugriff auf dein Account zu geben.

**Zugriff:** Öffne einen beliebigen Agenten im [Agent-Editor](/de/build/getting-started/agent-editor) und klicke oben rechts in der Toolbar auf **Teilen**.

## Was andere sehen

Die geteilte Seite zeigt ein gehostetes Demo-Erlebnis für diesen Agenten.

Je nach Link-Einstellungen können Besucher:

- den Namen und Avatar des Agenten sehen
- eine browserbasierte Voice-Demo starten
- das Live-Transcript während der Session lesen
- sehen, ob der Link abläuft oder eine begrenzte Demo-Nutzung hat

Wenn Live-Calls für den Link deaktiviert sind, kann die Seite weiterhin geöffnet werden, aber Besucher können keinen Live-Demo-Call starten.

## Erstelle einen Demo-Link

<Steps>
  <Step title="Share öffnen">
    Klicke im [Agent-Editor](/de/build/getting-started/agent-editor) in der Topbar auf **Teilen**.
  </Step>

  <Step title="Link benennen">
    Füge einen optionalen Namen hinzu, damit du den Link später wiedererkennst, zum Beispiel `Sales demo`, `Customer review` oder `Partner training`.
  </Step>

  <Step title="Zugriffslimits festlegen">
    Wähle ein Ablauf-Fenster wie **24 hours**, **7 days**, **30 days**, **No expiry** oder ein benutzerdefiniertes Datum und eine Uhrzeit. Du kannst auch eine maximale Anzahl an Demos festlegen.
  </Step>

  <Step title="Kopieren und senden">
    Erstelle den Link, kopiere ihn und sende ihn an die prüfende Person oder Kundschaft.
  </Step>
</Steps>

<Note>
Der Link wird nach dem Erstellen automatisch kopiert, aber du solltest ihn trotzdem an einem sicheren Ort speichern, falls andere Teammitglieder ihn später brauchen.
</Note>

## Bestehende Links verwalten

Nutze **Manage Links** im Share-Dialog, um vorhandene Links für den Agenten zu prüfen.

Die Link-Liste zeigt:

- **Name**
- **Created**
- **Expires**
- **Live calls**
- **Views**
- **Demos**
- **Actions**

Über das Aktionsmenü oder den Bearbeitungsdialog kannst du:

- einen Link umbenennen
- sein Ablaufdatum ändern
- das Demo-Limit festlegen oder ändern
- Live-Calls aktivieren oder deaktivieren
- den Link vollständig löschen

Das Löschen eines Links stoppt den Zugriff sofort für alle, die die URL noch haben.

## Views und Demos verstehen

- **Views** zählen, wie oft Personen die geteilte Seite geöffnet haben
- **Demos** zählen, wie viele Live-Demo-Sessions tatsächlich gestartet wurden

Das ist hilfreich, wenn du wissen willst, ob ein Link nur zur Prüfung geöffnet wurde oder in einer echten Produktdemo zum Einsatz kam.

## Best Practices

<AccordionGroup>
  <Accordion title="Nutze benannte Links für jede Zielgruppe" icon="tag">
    Erstelle getrennte Links für Sales-Demos, interne Reviews, Partner-Enablement oder die Freigabe durch Kundschaft, damit Reports leicht verständlich bleiben.
  </Accordion>

  <Accordion title="Setze standardmäßig ein Ablaufdatum" icon="clock">
    Kurzlebige Links verringern die Chance, dass ein alter Demo-Link weiter herumgereicht wird, nachdem sich der Agent geändert hat.
  </Accordion>

  <Accordion title="Nutze Demo-Limits für externe Weitergabe" icon="gauge-high">
    Wenn ein Link außerhalb deines Teams geteilt wird, begrenze die Anzahl der Demos, damit daraus kein offener öffentlicher Test-Link wird.
  </Accordion>

  <Accordion title="Deaktiviere Live-Calls, wenn die Prüfung abgeschlossen ist" icon="microphone-lines-slash">
    Behalte den Datensatz bei Bedarf als Referenz, aber schalte Live-Calls aus, wenn niemand den Agenten mehr testen soll.
  </Accordion>
</AccordionGroup>

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Die Seite öffnet sich, aber Besucher können keine Demo starten" icon="phone-slash">
    Prüfe, ob **Live calls** für diesen Link deaktiviert ist.
  </Accordion>

  <Accordion title="Der Link funktioniert nicht mehr" icon="link-slash">
    Der Link ist möglicherweise abgelaufen oder gelöscht worden. Erstelle einen neuen und sende ihn erneut.
  </Accordion>

  <Accordion title="Das Demo-Limit wurde erreicht" icon="ban">
    Bearbeite den Link und erhöhe das Demo-Limit oder erstelle einen neuen Link für die nächste prüfende Person.
  </Accordion>
</AccordionGroup>
