**Zugriff:** Nutze **Einstellungen → Account → Abrechnung → Aktuelles Abonnement**.

## Premium- und Zusatzkategorien

Premium- und Zusatzkosten erscheinen in der Abrechnung, wenn die entsprechenden Features genutzt werden.

## Was Kosten verursachen kann

| Kategorie in der Abrechnung | Typische Quelle |
|---------------------|-----------------|
| **Premium LLM** | Höherpreisige Sprachmodell-Optionen |
| **Premium STT** | Premium-Transkriptionsanbieter |
| **Premium-Stimme** | Premium-TTS- oder Voice-Anbieter |
| **Aufnahme** | Nutzung von Gesprächsaufzeichnungen |
| **Verbindung** | Gebühren für Outbound-Verbindungen |
| **Analyse** | Premium-Post-Call- oder Analysefunktionen |
| **Wissensdatenbanken** | Wissensabruf und RAG-Nutzung |
| **Websuche** | Web-Suchen durch Agenten oder Tools |
| **Minutenüberschreitung** | Nutzung über den inkludierten Minutenlimits |
| **Andere** | Zusätzliche abrechenbare Ereignisse, die oben nicht aufgeführt sind |

## Wo du diese Kosten siehst

In **Ausstehende Zusatzgebühren** enthält jede Position:
- **Element**
- **Nutzung**
- **Tarif**
- **Betrag**

Das gleiche Panel zeigt auch den Fortschritt zum aktuellen Auto-Charge-Schwellenwert.
