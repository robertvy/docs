**Zugriff:** Nutze **Einstellungen → Account → Billing → Current Subscription**.

## Premium- und Zusatzkategorien

Premium- und Zusatzkosten erscheinen im Billing, wenn die entsprechenden Features genutzt werden.

## Was Kosten verursachen kann

| Kategorie in Billing | Typische Quelle |
|---------------------|-----------------|
| **Premium LLM** | Höherpreisige Sprachmodell-Optionen |
| **Premium STT** | Premium-Transkriptionsanbieter |
| **Premium voice** | Premium-TTS- oder Voice-Anbieter |
| **Recording** | Nutzung von Gesprächsaufzeichnungen |
| **Connection** | Gebühren für Outbound-Verbindungen |
| **Analysis** | Premium-Post-Call- oder Analysefunktionen |
| **Knowledge bases** | Wissensabruf und RAG-Nutzung |
| **Web search** | Web-Suchen durch Agents oder Tools |
| **Minutes overage** | Nutzung über den inkludierten Minutenlimits |
| **Other** | Zusätzliche abrechenbare Ereignisse, die oben nicht aufgeführt sind |

## Wo du diese Kosten siehst

In **Pending Extra Charges** enthält jede Position:
- **Item**
- **Usage**
- **Rate**
- **Amount**

Das gleiche Panel zeigt auch den Fortschritt zum aktuellen Auto-Charge-Schwellenwert.
