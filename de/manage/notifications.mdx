## Benachrichtigungs-Postfach

Das Postfach öffnet sich als Vollseite mit folgendem Layout:

- **Header** - zeigt den Titel "Benachrichtigungen", ein Badge für ungelesene Einträge und die Schaltfläche **Alle als gelesen markieren**
- **Benachrichtigungsliste** - scrollbare Liste mit **Mehr laden**-Paginierung (20 Benachrichtigungen pro Seite)

### Benachrichtigungskarte

Jede Benachrichtigungskarte zeigt:

| Element | Details |
| --- | --- |
| **Ungelesen-Indikator** | Ein blauer Punkt für ungelesene Benachrichtigungen |
| **Symbol** | Ein Symbol für den Benachrichtigungstyp |
| **Titel und Zeit** | Ereignistitel mit relativem Zeitstempel |
| **Nachricht** | Zusätzlicher Kontext zum Ereignis |
| **Menü** | Optionen zum Markieren als gelesen/ungelesen oder zum Löschen der Benachrichtigung |

Wenn du auf eine Benachrichtigung klickst, wird sie als gelesen markiert und die Zeile erweitert. Wenn eine zugehörige Ressource verfügbar ist, nutze **Details anzeigen**, um sie zu öffnen.

## Benachrichtigungstypen

| Typ | Beschreibung |
| --- | --- |
| **Task zugewiesen** | Jemand hat dir einen Task zugewiesen |
| **Task erwähnt** | Jemand hat dich in einem Task-Kommentar erwähnt |
| **Issue zugewiesen** | Jemand hat dir ein Quality-Issue zugewiesen |
| **Issue erwähnt** | Jemand hat dich in einem Issue-Kommentar erwähnt |
| **Issue gelöst** | Jemand hat ein Issue gelöst, an dem du beteiligt bist |
| **Gespräch beendet** | Ein Gespräch wurde abgeschlossen |
| **Kampagne abgeschlossen** | Eine Outbound-[Kampagne](/de/manage/campaigns/overview) ist fertig gelaufen |
| **Insight bereit** | Ein neues KI-Insight steht zur Prüfung bereit |
| **Compliance freigegeben** | Jemand hat eine Compliance-Prüfung freigegeben |
| **Compliance abgelehnt** | Jemand hat eine Compliance-Prüfung abgelehnt |
| **System** | Plattformankündigungen, Wartung oder System-Updates |
