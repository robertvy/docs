**Access:** Use **Settings → Account → Billing**.

## Included Minutes and Overage

Each plan includes monthly voice minutes. When usage exceeds included minutes, overage charges apply based on your active plan configuration.

In **Current Subscription**, the usage panel shows:
- included minutes (or unlimited where applicable)
- minutes used for the current period
- overage context
- next reset date
- concurrent call capacity

---

## Usage Analytics

If your role can read usage data, a **Usage** tab is available in Billing. It includes:
- total minutes
- active days
- average minutes per active day
- date range selector
- daily/weekly/monthly aggregation
- grouping options (none, medium, agent)

If you do not see this tab, your account role likely does not include usage read permission.

---

## Pending Extra Charges

When applicable, Billing shows a **Pending Extra Charges** card with:
- current accumulated amount
- progress to auto-charge threshold
- line-item table with **Item**, **Usage**, **Rate**, and **Amount**

Common line items include:
- premium voice
- premium STT
- premium LLM
- recording
- premium analysis
- outbound connection
- knowledge bases
- web search
- minutes overage
- other

See [Premium Features](/billing/premium-features) for charge category details.
