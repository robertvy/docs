## January 2026 — Platform Upgrade

### Major New Features

<AccordionGroup>
  <Accordion title="Customizable Dashboard" icon="chart-mixed">
    **Your operational command center, fully customizable**

    A widget-based dashboard with drag-to-reorder layout, date range filtering, and one-click refresh. Widgets include usage metrics, call statistics, recent conversations, and agent performance summaries.

    - Drag-and-drop widget arrangement
    - Date range picker for time-based analysis
    - Reset to default layout anytime

    [Learn more →](/manage/dashboard)
  </Accordion>

  <Accordion title="Agent Builder Wizard" icon="wand-magic-sparkles">
    **Multi-step guided agent creation**

    A completely redesigned agent creation flow that walks you through each configuration step: identity, voice selection, prompt, ambient sound, greeting & farewell, goals, knowledge base, and tools.

    - Step-by-step guided setup
    - Voice preview with avatars and language filters
    - AI-guided setup suggestions
    - Progress tracking across steps

    [Learn more →](/build/getting-started/create-first-agent)
  </Accordion>

  <Accordion title="Task Management" icon="list-check">
    **Kanban, list, and calendar views for action items**

    Track follow-ups and action items from conversations or create tasks manually. Organize with Kanban boards, sortable tables, or a full calendar view with drag-and-drop support.

    - Three views: Kanban, List, Calendar
    - Drag-and-drop between statuses
    - Bulk actions via floating action bar
    - Task properties: priority, assignee, due date, tags

    [Learn more →](/manage/tasks/overview)
  </Accordion>

  <Accordion title="Contact Management" icon="address-book">
    **Import, segment, and manage your contact database**

    A full contact management system with CSV import, search, filters, tags, and bulk operations. View conversation history per contact and assign contacts to campaigns.

    - CSV import with preview validation
    - Tag-based segmentation
    - Contact detail with conversation history
    - Bulk operations (tag, delete, export)

    [Learn more →](/manage/contacts/overview)
  </Accordion>

  <Accordion title="Campaign Management" icon="bullhorn">
    **Outbound campaigns with analytics and contact tracking**

    Create, schedule, and monitor outbound calling campaigns. Assign agents and contact lists, configure retry logic and call windows, and track performance with detailed analytics.

    - Campaign creation with scheduling
    - Contact-level call tracking
    - Performance analytics dashboard
    - Call outcome breakdown

    [Learn more →](/manage/campaigns/overview)
  </Accordion>

  <Accordion title="Quality Studio" icon="microscope">
    **QA monitoring and issue resolution**

    Monitor conversation quality with automated checks, flag issues, and track resolution. Dashboard with quality scores, trend charts, and a structured issue workflow.

    - Quality metrics and trends
    - Automated issue detection
    - Issue resolution workflow (open → investigating → resolved)
    - Manual issue flagging from conversations

    [Learn more →](/manage/quality-studio/overview)
  </Accordion>

  <Accordion title="Trust Center" icon="shield-check">
    **Data privacy and compliance hub**

    Centralized compliance management with configurable data retention policies, General Data Protection Regulation (GDPR) data-request exports, and public Trust Center publishing.

    - Configurable retention policies per data type
    - GDPR-style account and contact data requests
    - Public Trust Center page for customer transparency

    [Learn more →](/manage/trust-center/overview)
  </Accordion>

  <Accordion title="Web Widget Editor" icon="browser">
    **Visual widget configuration with tabs**

    A redesigned widget editor with eight configuration tabs: Setup, Appearance, Content, Features, Actions, Privacy, Share, and Export. Customize every aspect of your web widget without code.

    - Visual editor with live preview
    - Setup and domain controls
    - Appearance, content labels, and feature toggles
    - Action links, privacy settings, share links, and export code

    [Learn more →](/manage/web-widgets/configuration)
  </Accordion>

  <Accordion title="Notification Center" icon="bell">
    **In-app notification inbox**

    Stay informed with a dedicated in-app notification inbox for conversation alerts, campaign updates, quality issues, and system events.

    - Notification inbox in the app sidebar
    - Unread count badges
    - Mark read, mark unread, and delete actions
    - Links back to related conversations, tasks, or issues

    [Learn more →](/manage/notifications)
  </Accordion>

  <Accordion title="Security Settings" icon="lock">
    **2FA, sessions, and enhanced security**

    Enable two-factor authentication, manage active sessions, and update your password. Protect your account with email-based 2FA and session revocation.

    - Email-based two-factor authentication
    - Active session management
    - Session revocation
    - Password management

    [Learn more →](/accounts/security)
  </Accordion>

  <Accordion title="Integrations Page" icon="plug">
    **Cal.com, webhooks, and third-party connections**

    A dedicated integrations page for connecting Cal.com calendars, configuring webhooks, and managing third-party service connections.

    - Cal.com calendar integration
    - Webhook configuration with event types
    - MCP server management link

    [Learn more →](/accounts/integrations)
  </Accordion>
</AccordionGroup>

### Additional New Features

<AccordionGroup>
  <Accordion title="Smart Filler" icon="bolt">
    **Reduce perceived latency with intelligent filler responses**

    Smart Filler generates quick acknowledgments ("Let me check that for you...") while your agent processes the full response. This reduces wait times during complex queries.

    - Customizable filler prompts for brand voice consistency
    - Language-aware filler generation
    - Works alongside Thinking Sounds for comprehensive latency management

    [Learn more →](/build/advanced/smart-filler)
  </Accordion>

  <Accordion title="Thinking Sounds" icon="keyboard">
    **Audio feedback during agent processing**

    Add realistic keyboard typing sounds while your agent processes responses. Creates a natural "someone is working on your request" feeling during actions and AI processing.

    - Automatic triggering during processing states
    - Configurable in General → Sounds
    - Complements Smart Filler for natural conversation flow

    [Learn more →](/build/voice-speech/thinking-sounds)
  </Accordion>

  <Accordion title="Web Search Tool" icon="magnifying-glass">
    **Real-time web search during conversations**

    Enable your agent to search the web for current information during conversations. Perfect for questions about recent events, competitor information, or data not in your knowledge base.

    - Configurable search depth (Basic/Advanced)
    - Domain restrictions for focused searches
    - AI-generated answer summaries
    - Customizable filler phrases during search

    [Learn more →](/build/tools/web-search)
  </Accordion>

  <Accordion title="Voice Cloning" icon="clone">
    **Create custom voices from audio samples**

    Upload voice samples to create custom AI voices for your agents. Perfect for brand consistency or unique character voices.

    - Support for MP3, WAV, M4A, OGG formats
    - Account-wide voice library
    - Works with all voice settings and pronunciations

    [Learn more →](/build/voice-speech/voice-cloning)
  </Accordion>

  <Accordion title="Recording Opt-Out" icon="shield-halved">
    **Allow callers to stop and delete recordings**

    Enable GDPR-compliant recording opt-out. When activated, callers can request to stop recording and delete any recorded audio during the call.

    - Automatic recognition of opt-out requests
    - Immediate recording stop and deletion
    - Configurable per agent

    [Learn more →](/build/advanced/recording-opt-out)
  </Accordion>

  <Accordion title="Widget Trust Center" icon="building-shield">
    **Public privacy information for web widgets**

    Create a public Trust Center page for your web widgets. Show visitors your privacy practices, link to your privacy policy, and list data subprocessors.

    - Auto-generated public URL
    - Customizable privacy policy and subprocessors links
    - Builds customer trust before conversations

    [Learn more →](/manage/web-widgets/configuration#trust-center)
  </Accordion>

  <Accordion title="Custom MCP Servers" icon="server">
    **Connect your own MCP servers**

    Full support for custom Model Context Protocol (MCP) servers. Connect your own MCP endpoints with custom headers, query parameters, and tool management.

    - Direct URL connection
    - Automatic tool discovery
    - Granular tool enable/disable
    - Secret-backed headers and query parameters

    [Learn more →](/build/advanced/mcp-servers)
  </Accordion>
</AccordionGroup>

### Improvements

- **Actions renamed to Tools:** Agent capabilities previously called "actions" are now called "tools" across the platform and documentation
- **Announcements:** Enhanced audio upload support with MP3, OGG, WAV formats (up to 10MB)
- **Custom Ambient Sounds:** Upload your own background audio for unique agent atmospheres
- **Widget Share Links:** Create demo links with expiration dates and usage limits
- **Performance:** Faster agent response times
